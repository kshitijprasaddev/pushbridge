# Third-party components

The frontend uses React and Three.js (MIT), Vite (MIT), Inter (SIL Open Font License), and IBM Plex Mono (SIL Open Font License). Exact versions and dependency integrity are recorded in `pnpm-lock.yaml`.

Font license texts are included under `public/licenses/`. Robot geometry, lab materials and labels are created in source code. No remote models, environment maps or fonts are requested by the rendered app.
